# 多人抢矿 · 为什么要换一台矿机？

2026-11-25｜第一轮参考游戏拆解与制作单

当前原型已经能换机、搬石、打灯、交易。还有一个值得试玩的问题：两台都空着时，玩家为什么要多走几步换一台？这一轮把机台的适用货物做出区别，观察玩家会不会在出钩前先选工位。

## 四款作品，对应四个设计问题

| 作品与可核实的机制 | 玩家在什么时候作决定 | 对本作的判断 |

| 《渔力全开》支持 1–4 人。捕鱼、处理、出售依次有自己的操作，挣钱后可换装备、接任务、去新岛。[商店](https://store.steampowered.com/app/4001890/) | 取货前选位置和装备，取到货后仍有加工与运输。官方介绍能确认这些操作，玩家具体怎样分工有待实机观察。 | 把“选机器”放在“选石头”之前。机器越远，走过去与扛回来的时间就越值得计算。 |
| 《黄金矿工：派对狂欢》让多人在同场争宝物，快速对战六关计分，关间有商店。[商店](https://store.steampowered.com/app/4815320/) | 选择大矿意味着自己的钩较长时间在回程，另一人可以改抓别处。此处对回程机会的解释是设计推断。 | 速度优势要能被对手看出来；公开机种和占用者，另一人可以抢位，也可以趁空档采矿。 |

## 本轮制作单 · 公共矿机专长

**决策假设。** 玩家看到一片碎金时愿意用快卷机；看到一块巨金时，愿意先走到重载机。给两种机台同样的倍率，让选位主要取决于目标和路程。

- 按编号交替分配。1、3 号为快卷机，碎金、普通金块回收速度乘 1.35。2、4 号为重载机，巨金、石块回收速度乘 1.35。二人局天然具备两种工位。
- 宝石、空钩、货箱按已有速度回收。多人合拉时使用主钩的机台与装备，截货后使用新货主的机台与装备。钱包、装备、分成与出钩占机沿用已有规则。
- 在矿机编号旁显示机种，玩家站到机旁能看见适用货物与倍率。矿物从地下到井口的实际回收运动承担主要反馈。
- 例：基础回收需 4 秒的重物，用重载机约需 2.96 秒，省约 1.04 秒。若换位多花 2 秒，本次搬运可能得不偿失。倍率只作用于回收段。

## 如何判断这轮是否成立

工程验收使用固定货物、相同距离、相同个人升级对照两种机型；再测 P1 使用 2 号机、P2 使用 1 号机、在途读档及两端显示。真人试玩先让两人自由选位，再给他们相近距离的一轻一重两块矿。记录目标、选机、走动时间和回程时间。若玩家看懂标签却总不换位，比较节省的时间与步行成本；若看不懂标签，先改提示再调倍率。

**留待下一轮。** 如果玩家更在意验石后的选择，再比较“卖晶心赚启动金”和“留晶心建切割台”。切割台需要新增库存与加工决策，适合独立验证。
## 本轮实现与验收记录

网页版与 Godot 版已接入公共矿机专长。Edge 打开本地 HTML 后，以相同初始条件对比两台机的回收速度。碎金为 297 / 220，金块为 195.75 / 145，巨金为 82 / 110.70，石块为 90 / 121.50，单位均为像素/秒，顺序为快卷机 / 重载机。宝石两端均为 135，空钩均为 350，补给箱均为 220。Godot 4.6.2 的 328 像素巨金回程实测约为 4.01 / 2.97 秒，已检查两名矿工互换机位、在途读档及与个人绞盘、合拉速度叠加。

待真人试玩验证的问题：面对相同距离的一轻一重两块矿，玩家是否会主动换机，能否说出换位的原因。若试出差异，下一轮将实际操作与当前假设对照后再调整倍率或矿位。
