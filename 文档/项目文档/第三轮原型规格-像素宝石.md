# 像素宝石 · 第三轮原型规格

依据[视频参考拆解](../拆解分析/第三轮参考拆解-像素宝石.md)。使用原创像素图集，以两种色相和连续切面帧展示成品。加工阶段可由剩余工时驱动显露比例，成品循环展示切面变化。宝石颜色根据货物现有字段稳定选择，读档及多人两端可复现同一外观。未开石时保持石壳。柜台须能分辨原石、切割中与切割成品，报价和出售操作始终可用到适当阶段。

使用现有 8 金与 3 秒规则；不新增收费或随机抽取。检查两种成品、加工边界、旧成品恢复、离线 HTML 资源、Godot 实际显示及多人分别持货。提供一个直达展示的试玩入口，使未解锁切割台的玩家也可看样品，样品不进入账本。
